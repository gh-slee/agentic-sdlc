# ASD-P1-007: Add a reviewed upgrade path for adopted projects

## Goal

Adopters now upgrade by hand (docs/versioning.md). Add a tool that proposes an upgrade from the installed pinned version to a newer one as a reviewable diff, never applying it automatically and never weakening project overrides.

## Acceptance criteria

- [ ] Upgrade proposal shows per-file changes and provenance hashes.
- [ ] Local modifications and stricter project rules are preserved and reported.
- [ ] Interruption and rollback tests pass; independent review recorded.
