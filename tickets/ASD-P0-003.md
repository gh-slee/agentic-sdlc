# ASD-P0-003: Install the agent ticket workflow for parallel agents

## Goal

Give this repository a tracked Markdown ticket backlog and the `scripts/tickets.py` claim tool so several coding agents (Codex, Claude Code, opencode) can work different tickets at once and resume each other's work after usage limits, without weakening the publication audit.

## Acceptance criteria

- [ ] `scripts/tickets.py`, `tests/test_tickets.py`, `tickets/README.md`, `tickets/TEMPLATE.md`, `tickets/ROADMAP.md` and one ticket per work item are committed.
- [ ] AGENTS.md has the "Tickets and parallel agents" section; CLAUDE.md loads `@AGENTS.md`; `/work/` is ignored.
- [ ] `scripts/check_publication.py` accepts only single-segment `tickets/*.md` files outside PUBLIC_FILES.json, still scans their content, and has a regression test.
- [ ] ADR-002 records how the ticket workflow relates to ADR-001 and core/lifecycle.md.
- [ ] Full unit suite, framework check, publication audits (worktree, index, history) and `tickets.py check` pass locally and in CI.
- [ ] An independent session reviews the publication-audit change before merge.
