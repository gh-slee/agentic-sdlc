# Source preservation review

The [matrix](preservation.csv) classifies 36 material engineering rules against a [pinned tracked-file inventory](source-provenance.json). Read it as an audit of documented behavior and observed enforcement, not certification that every agent followed a rule. No source code or role prose is copied into the generic core. Detailed source snapshots stay ignored locally.

Coverage includes root instructions, four public role skills, spec and agent workflows, approvals/reservations/transfers, pause/resume, PR template/checker/publisher/tests, candidate-image gate, public allowlist/history/symlink controls, hooks, CI, security and contribution guidance. No nested tracked AGENTS.md exists in this inventory. Private overrides and untracked plans were not read.

Public PR evidence inspected: [PR24](https://github.com/gh-slee/wealth-ledger/pull/24) shows canonical PR evidence categories and explicit NOT RUN independent review; [PR23](https://github.com/gh-slee/wealth-ledger/pull/23) shows safe writing-skill setup and honest discovery limits; [PR22](https://github.com/gh-slee/wealth-ledger/pull/22) distinguishes independent acceptance, default-suite skips and later integration checks. These are historical source reports, not tests run by this framework.

The source Architect skill contains an outdated capability statement compared with newer source/PR evidence. Classify it as legacy; do not copy stack or capability claims. Source-specific finance, locale, runtime-image, merge-to-DONE, four-skill allowlist and private owner rules remain local to that project. Optional third-party style downloads are not needed in this release.

Every row retains the source rule unchanged. Universal principles are rewritten in original domain-neutral language. Configurable/tool/optional rules carry explicit ownership and limits. Compatibility simulation must demonstrate that new skill paths are refused by the source publication allowlist until deliberately reviewed, rather than widening it.
