# Security policy

Use GitHub private vulnerability reporting if enabled. Otherwise contact the maintainer through GitHub to arrange a private channel before sharing sensitive details. Do not publish credentials, private policies, user data or full local logs. Provide a synthetic reproduction, version/revision, environment and expected/actual behavior.

Stop affected publication after suspected disclosure, revoke exposed credentials and inspect reachable history and remote artifacts. Deleting from HEAD is insufficient. See [implemented controls and limits](docs/security-model.md). Initially only the latest 0.1.x source line is supported; no historical maintenance or signed-release guarantee is offered.
