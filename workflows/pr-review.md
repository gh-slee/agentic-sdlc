# Pr-Review workflow

Read [core policy](../core/policy.md), [lifecycle](../core/lifecycle.md) and [evidence](../core/evidence.md); preserve stronger project rules.

Read actual base-to-head diff and current evidence; compare scope, invariants, compatibility, security and negative cases. Check claims against commands/results and CI links. Report actionable defects with precise locations. A review does not grant publication, merge or deployment authority.
