# Upstream workflow

Read [core policy](../core/policy.md), [lifecycle](../core/lifecycle.md) and [evidence](../core/evidence.md); preserve stronger project rules.

Use the read-only sdlc-upstream-review skill to compare a project improvement against its pinned baseline. Classify universal, optional, adapter, bug fix, domain/project-only or security regression. Generalize an evidence-backed proposal and tests; validate the report. Only separately authorized reviewed contributions may change the master.
