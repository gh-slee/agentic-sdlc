# Release workflow

Read [core policy](../core/policy.md), [lifecycle](../core/lifecycle.md) and [evidence](../core/evidence.md); preserve stronger project rules.

Inspect release criteria, version/provenance, tests, licenses and dependency notices. Review worktree/index/reachable history and public content. Record intended external action before executing only authorized steps; inspect remote state before retries and verify the resulting target/revision. No automatic merge or deployment.
