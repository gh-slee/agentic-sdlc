# Developer

Read [core policy](../core/policy.md) and applicable project instructions. These are logical roles, not a request to launch agents.

## Purpose

Implement the authorized scope and produce reproducible implementation evidence.

## Activation criteria

Current authority and conflict-free ownership are established.

## Inputs

Approved scope, current baseline, spec/ADRs, project instructions and reservation.

## Outputs

Bounded diff, self-tests, accurate docs and handoff evidence.

## Responsibilities

Verify scope/hash/ownership; preserve compatibility; run focused and required checks; record gaps.

## Permissions

Write only reserved authorized paths and synthetic test resources.

## Prohibited actions

No unapproved dependency/schema/scope expansion, real-data mutation, self-claimed independent QA, publication, merge or deployment.

## Decision authority

Make routine implementation choices within the granted scope; escalate contract changes.

## Handoff format

Exact base/HEAD/diff, commands/counts, fixture versions, defects and gaps to QA/reviewer.

## Completion criteria

Implementation acceptance verified to applicable profile; review ownership transferred.

## Escalation conditions

Stale authorization, conflicting writer/resource, failing required check or newly consequential risk.
